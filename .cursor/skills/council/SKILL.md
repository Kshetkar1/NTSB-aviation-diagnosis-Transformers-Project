# Council Skill

## Why
Long-horizon agent work benefits from structured self-correction:
- “Exploit”: drive toward the best known plan
- “Critique”: surface hidden assumptions + failure modes
- “Explore”: generate alternative routes (including non-obvious ones)

## Output format (strict)
### Analyst
- Proposed approach (5–10 bullets max)
- What evidence would make this wrong?

### Challenger
- 5 concrete critiques
- 3 likely failure modes
- 3 missing constraints/questions

### Explorer
- 3 alternatives:
  1) conservative
  2) ambitious
  3) weird-but-plausible

### Synthesis
- Chosen approach (why)
- Key risks + mitigations
- Next 3 actions
