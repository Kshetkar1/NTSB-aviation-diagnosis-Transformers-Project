# GSD Workflow (Split)

The GSD workflow is now split into two phases to ensure quality.

**Phase 1: Specification**
Run `/gsd-spec` to generate the Onboarding doc and PRD.
*User must review and approve.*

**Phase 2: Planning**
Run `/gsd-plan` to generate the Implementation Plan and Task DAG.
*User must review before execution.*

**Phase 3: Execution**
Run `/ralf` to execute the tasks.
