Transition Probability Investigation

Analysed 152 Markov chain transition edges across 30 clusters using all incidents per cluster (full dataset, not capped).
This answers: "Why do many causal chain diagrams show 100% transition probabilities?"

Why 100% is mathematically correct — not a bug:

A transition probability of 100% means: "in every incident of this type in this cluster, event A was always followed by event B."

Example: In an Engine Fire cluster, "Inflight Engine Fire" → "Emergency Declaration" appears in every engine fire incident → transition probability = 100%. This is accurate — it is truly always the next step in this type of accident.

The non-100% edges (shown here using ALL cluster incidents, not capped) are where incidents diverge: some had structural damage, some had injuries, some diverted. Those show the actual probability split (e.g., 60% → "Substantial Damage", 40% → "Minor Damage").

Note on the live app: The Mermaid diagram in the Streamlit app caps at 20 incidents for readability — a visualization limit, not a statistical one.
