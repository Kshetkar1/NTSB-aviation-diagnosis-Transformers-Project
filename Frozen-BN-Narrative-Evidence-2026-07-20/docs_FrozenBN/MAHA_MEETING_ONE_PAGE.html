Pipeline — every step (what · why)

1
Remove outcome phrases from the narrative
What: Strip phrases like “fatal injury” or “substantial damage” before any matching or similarity search.
Why: The narrative often already states the answer — using that wording would be cheating.
STEPS 2 & 3 — SAME TIME, same cleaned narrative
Step 2 · Keyword match What: If words/phrases in the narrative match a keyword list, we turn on the matching network node (e.g. “fire”, “stall”, “pilot”).
Not every node: Only nodes we have keywords for — built from Zhang/NTSB coded event and finding labels (our phrase dictionary). No match → that node stays unset from this step.
Why: Uses the same vocabulary Zhang’s network was built from when the narrative actually names those facts.
∥
Step 3 · 100 most similar past narratives What: Compare the cleaned narrative to all 1982–2006 narratives in our list; keep the 100 closest by text similarity.
Why: When keywords miss, past similar accidents still carry information — and we never add the 296 newer accidents to this list.
STEPS 4a & 4b — SAME TIME, same 100 accidents
Step 4a · Event hints from the 100 What: For event-type nodes, count how many of the 100 had that code (71/100 → set strength 0.71 on that node).
Why: The new narrative may not name an event clearly, but similar past accidents often share event patterns — this fills gaps keyword match missed.
∥
Step 4b · Injury & damage codes from the 100 What: Look up the official NTSB injury and damage codes stored on those 100 records (not words in the new narrative). Count each level (e.g. 41 none, 28 minor…) → turn into fractions → set the network’s injury and damage nodes to those fractions.
Why: This is our main severity path — severity from how similar past accidents were coded, without reading outcome phrases from the new narrative.
↓
What actually goes into the network in Step 5?
The network has many nodes (fire yes/no, injury level, damage level, etc.). Steps 2–4 decide which nodes to set and what values:
· Step 2 → matched nodes set to yes
· Step 4a → event nodes set to fractions (0–1)
· Step 4b → injury/damage nodes set to level fractions
Step 5 loads those node values into the fixed network and runs the probability math once. We do not put raw narrative text into the network — only node values.
Main result (90.9% / 77.4%): use Step 4b only on injury/damage nodes. If we also merge Step 2 + 4a + 4b together → 38.5% / 41.9% (failed — double-counting).
5
Update the fixed network
Set the node values from above; network computes updated probabilities. Network tables were fixed from 1982–2006 — we do not relearn from the 296 accidents.
6A
Severity answer
Pick injury level and damage level with highest probability → 90.9% / 77.4%.
6B
Cause answer
Vote 4 categories from the 100 similar accidents’ coded findings → 84.2%.
↓
7
Grade vs NTSB codes
Compare prediction to official codes. Codes were never inputs in Steps 1–6. Compare to NTSB — not to Zhang’s percentages.

FAQ — things Maha might drill

Are keyword matches all network nodes?
No. The network has thousands of nodes from NTSB codes. We only set nodes we have keywords for (multi-word phrases from Zhang/NTSB coded labels). If the narrative uses words outside that dictionary, keyword match sets nothing — then the 100 similar accidents matter more.
Is the keyword list the same as NTSB codes?
Related, not identical. Network nodes come from NTSB coded event/finding labels Zhang used. Our keyword list maps narrative wording to those node names. Official codes are only used at Step 7 to grade — and on the 100 past records in Step 4b/6B.
1982–2006 — not “training” for our method
Build years: network structure, probability tables, similarity list, keyword rules — all fixed from these accidents. We do not adjust them using the 296 newer accidents.
Exception: TF-IDF and other comparison classifiers learn word patterns from 1982–2006 narratives + codes — that is separate from our main pipeline.
2007–2019 — not “held-out test” jargon
Scoring years: accidents that happened after the network was built. We run our pipeline on their narratives and compare to NTSB codes. None of these 296 were in the 1982–2006 similarity list.
“Do narratives beat doing nothing?”
Beat the dumb baseline (always guess no injury = 58.4%) — yes, 90.9%.
Beat every comparison method — no (TF-IDF 92.2%, cause vote path is the main dx readout not BN). Say which you mean.
